## 📌 Philosophy & Learning Approach

### 🚀 Why I Go Beyond Frameworks

In the modern development world, frameworks like Spring Boot, Hibernate, and containers like Tomcat help developers move fast — but they also hide a lot of the core logic behind abstraction.

I believe that to become a truly skilled backend engineer, it’s not enough to *use* frameworks — I need to understand **how they work under the hood**.

That’s why I challenge myself to rebuild core concepts such as:

- HTTP servers and servlet containers in pure Java  
- Custom routing and request dispatching mechanisms  
- Thread and connection management using sockets  
- Manual dependency injection and lifecycle control  
- Core features like JWT, i18n, DTO mapping without external libraries  

These projects are not for production use — they are **hands-on labs** to deeply understand the foundations behind popular technologies.

I aim to become an engineer who’s not just framework-dependent, but **framework-aware** and capable of solving problems from scratch when needed.
